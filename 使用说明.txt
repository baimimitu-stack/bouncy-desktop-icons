蹦蹦图标 · 使用说明书
简易 / 标准 / 进阶

一、一个程序，三个模式

简易模式：GIF 原地播放，可以开启或关闭上下弹动。
适合只想要一个会动的应用入口、不需要它到处跑的情况。

标准模式：在你框定的范围内随机游走，可调整大小和速度。
鼠标靠近时会停下来，方便双击或拖动。

进阶模式：包含标准模式的游走，再加上觅食、吃草、文件夹零食和休息。
“吃文件夹”只吃动画副本，真实文件夹不会被删除、移动或改名。

三个模式都能打开你绑定的 app，不只是桌面装饰。
只需一个桌面入口。在管理器顶部或挂件设置的“全局模式”中切换。
切换立即生效，影响全部挂件，无需重启。
三个模式共用应用列表、GIF、大小和绑定目标。
首次启动会将旧版绑定和图片复制到共用目录，保留旧数据。

二、添加一个应用挂件

1. 打开蹦蹦图标管理器，点“添加应用挂件”。
2. 选择要打开的快捷方式（.lnk）、程序（.exe）或文件。
   如果想打开文件夹，点“绑定文件夹”。
3. 选择匹配的 GIF，点“添加”。

也可以把快捷方式、程序、图片或 GIF 拖进管理器，再补齐绑定。
静态图片和 GIF 都选了时，优先显示 GIF；都没选就使用默认文件夹。
图片本身不包含应用地址，需要另选要打开的 app。

三、桌面上怎么操作

双击 GIF 或下方名称：打开绑定的应用、文件或文件夹。
如果还没有绑定目标，双击会打开挂件设置。
单击：进阶模式会触发摸摸、害羞、好奇等反应；其他模式不触发互动。
为区分双击，反应会等待系统的双击判定时间；双击只打开应用。
左键按住并移动：拖动挂件；松手保存位置。
右键：打开设置、重新绑定目标、找回挂件或阅读说明书。

标准模式和进阶模式拖动时会暂停游走；松手后活动范围跟着平移，
原范围的大小不变。拖动不会触发应用启动。

四、更换 GIF、调整大小

在管理器中选中一个挂件，再点“设置 / 换 GIF”。
也可以右键桌面挂件进入设置。

“选择 GIF”：导入本地 GIF，最大 20 MB，宽高不超过 4096。
“恢复默认”：恢复默认的小文件夹素材。
“大小”：32–256 像素，设置后立即更新。
“原地弹动”：控制额外的上下弹动；关闭后 GIF 自身仍会播放。
“保持置顶”：开启后显示在其他窗口上方。

导入的图片会复制到本机配置目录，不会上传网络。
素材原文件移动后仍可显示；绑定的 app 或快捷方式移动后需要重新绑定。

五、设置活动范围（标准 / 进阶）

在设置中点“框选活动范围”，在主屏上按住左键拖出矩形，松手保存。
按 Esc 可以取消。范围太小无法容纳挂件时会自动扩大。
“速度”控制游走速度。
取消勾选“在范围内随机游走”或“随机游走、觅食和休息”可暂停跑动。

当前活动范围以主显示器的可用区域为准，不支持跨屏范围。

六、进阶模式怎么投喂

右键挂件 → “投喂草”，会出现虚拟草。
右键 → “投喂文件夹（仅动画）”，或把文件夹拖到挂件上，
会出现一个文件夹零食副本。挂件会靠近、咀嚼，再移除动画副本。
真实文件不受影响。最多同时保留 8 个食物。

七、看不见挂件时

系统托盘中找到蹦蹦图标，右键 → “找回全部挂件”。
也可以在管理器中选中一项，点“找回”。
找回会重置位置和活动范围，并重新置顶。
如果关闭了置顶，挂件可能被其他窗口盖住。

八、关闭面板、退出、开机启动

关闭管理器窗口：只隐藏管理面板，挂件继续运行。
完全退出：托盘或挂件右键 → “退出所有挂件”。
移除挂件：只移除这个入口，不删除对应应用或真实文件。

想登录 Windows 后自动出现，可以在设置勾选对应选项。
默认不开启。整个程序共用一个开机启动选项。

GIF 持续播放需要一个后台进程；它不是零后台的 Windows 动态图标。
不必一直打开管理面板，但完全退出后动画就会停止。

九、文件与版本

统一程序：BouncyIcons.exe
解压下载包时请保留程序旁的 assets 文件夹。

配置位置：%LOCALAPPDATA%\BouncyIcons\shared\
项目与下载：https://github.com/baimimitu-stack/bouncy-desktop-icons

默认素材和代码采用 MIT 许可证。你导入的素材仍归原作者所有。

十、进阶模式：心情与伙伴互动

在设置里切换到“进阶”，可分别开关“点击心情反应”和“与其他挂件互动”。
单击可能开心、害羞或好奇，显示短气泡并跳动；短时间连续戳会闹小脾气。
心情会逐渐恢复悠闲。互动暂停游走几秒，气泡自动消失，不抢键盘焦点。
双击仍然打开绑定的应用，拖动不触发点击反应。

两个本管理器内的进阶挂件靠近，会打招呼、约散步或拌嘴。
双方都需要开启伙伴互动；每次互动后冷却约 22 秒。
可以把两个挂件拖到一起，松手后等待片刻。只有一个挂件时没有伙伴对话。
普通 Windows 图标、其他程序的宠物不会参与；不会读取其他 app 内容。
开着设置、拖动、睡觉或吃东西时，不主动发起伙伴对话。

导入的 GIF 同样有气泡、动作与心情文字，程序不会重画原 GIF 的角色表情。
默认素材更新为眨眼的小文件夹；自定义素材保持原样。
所有互动在本机运行，不需要联网；重启后心情回到悠闲。

十一、自定义反应（多张 GIF）

挂件右键 → “反应素材库（多 GIF）”，或设置 → “反应素材库”。
选择开心、害羞、好奇、小脾气、打招呼、拌嘴、悠闲中的一类。
点“批量添加 GIF”可一次选择多张；同类素材会在触发时随机选择。
每张 GIF 可以单独设置气泡台词和 1–30 秒播放时长，点保存后生效。
台词留空使用原反应台词。点预览可在桌面挂件上查看效果。
自动反应在进阶模式生效；其他模式也可以导入和预览素材。
心情恢复悠闲时可触发“悠闲”素材；未配置素材的反应沿用日常 GIF。

每张最大 20 MB、宽高不超过 4096。导入后复制到本机配置目录，不上传网络。
播放结束、切换模式或关闭素材库后恢复日常 GIF，不改变应用绑定。
“移除素材”只删除本机导入的副本，不删除你选择的源文件。
各挂件拥有自己的反应素材库；三个模式共用。

十二、手动 API 聊天

挂件右键 → “和挂件聊天 / API 设置”，或设置 → “API 聊天”。
在 API 设置页填写完整 Chat Completions 接口地址、模型名、API 密钥。
完整地址示例：https://你的服务/v1/chat/completions（示例不是可用服务）。
模型名以你的服务商为准；支持 HTTPS，以及本机 http://localhost 服务。
可编辑挂件人设。API 连接设置和人设全局共用，保存设置不发起请求。
密钥以 Windows 当前用户加密保存，不能直接复制到另一账户使用。

聊天页输入文字，点击“发送”才会调用接口。可取消请求，超时约 45 秒。
只发送人设、输入的文字和最近 6 轮对话，不发送 GIF、绑定路径或电脑文件。
API 回复不会运行命令、操作电脑或打开文件。费用由所填服务商按其规则计算。
每个挂件的聊天窗口独立保留临时上下文，关闭窗口或清空聊天后不再保留。
修改并保存 API 设置会清空当前窗口上下文；其他已打开的聊天窗口重新打开后读取新设置。
进阶模式收到回复时会显示短气泡，并可触发好奇分类的 GIF；完整内容在聊天框阅读。
普通点击、伙伴对话、拌嘴不会调用 API。

本版本使用模拟接口测试成功回复、失败、取消和密钥加密。
真实服务需要你自己的有效地址、模型和密钥，未内置任何可用密钥。
