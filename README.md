# 蹦蹦图标 · Bouncy Desktop Icons

把常用应用的入口变成 GIF 挂件。一个管理器可放多个应用，每个应用可以绑定自己的快捷方式、图片和 GIF。

**这是透明的桌面入口层，不会修改 Windows Explorer 的图标格式。GIF 要持续播放，就需要程序持续运行；关闭管理面板后，挂件仍可运行。完全退出程序后，动画会停止。**

## 三个原生版本

| 版本 | 程序 | 行为 |
| --- | --- | --- |
| 低配版 | `BouncyIcons-Lite.exe` | 原地播放 GIF，可开关弹动；没有游走和觅食逻辑 |
| 中等版 | `BouncyIcons-Standard.exe` | 在框定范围内随机游走，可改大小、速度，鼠标靠近时暂停 |
| 专业版 | `BouncyIcons-Pro.exe` | 游走、饥饿、觅食、吃草、文件夹零食和休息状态机 |

三个版本均使用 C# / Windows Forms，不依赖 Electron、Node.js 或浏览器。每个版本的多个挂件共用一个进程；不同版本的设置相互独立。建议按需要使用其中一个版本。

本仓库只包含独立的通用原生实现，不包含原有日志应用的代码或用户数据。

## 使用

从 [Releases](https://github.com/baimimitu-stack/bouncy-desktop-icons/releases) 下载 ZIP，解压整个目录，保留程序旁的 `assets` 文件夹，运行想用的版本。

1. 在管理器点 **添加应用挂件**，选择 `.lnk` / `.url` / `.exe`，或绑定文件夹。
2. 选择图片或匹配的 GIF，点 **添加**。GIF 优先于静态图片；没选素材则用默认文件夹。
3. 点击挂件打开绑定目标。右键进入设置、换 GIF 或管理全部挂件。

也可以把一个快捷方式、程序、文件夹或图片拖入管理器。图片本身不包含“打开哪个 app”的信息，需在添加面板指定目标。支持普通文件系统快捷方式；应用商店中没有可选路径的应用，需要先有对应的快捷方式。

- 大小：32–256 像素。
- 可选 **登录 Windows 后自动出现**，默认关闭；只写当前用户的启动项。
- 右键托盘 → **管理所有应用挂件** 或 **找回全部挂件**。
- 使用 `BouncyIcons-Lite.exe --manage`（其他版本同理）可在启动时直接打开管理器；普通启动及开机启动不强制打开管理面板。
- 关闭管理面板只隐藏面板。真正退出用托盘 → **退出所有挂件**。
- 移除挂件只移除管理器条目，不删除 app、快捷方式或目标文件。
- 导入的 GIF / 图片复制到本机配置目录，原素材移动后仍可使用。原 app 或快捷方式移动后需要重新绑定。

## 专业版的“吃文件夹”

右键选择 **投喂文件夹（仅动画）**，或把文件夹拖到挂件上。应用生成一个虚拟文件夹零食，宠物靠近后播放咀嚼状态并移除这个动画副本。

不会移动、隐藏、重命名、修改或删除真实文件夹，也不会扫描桌面文件内容。草是程序绘制的虚拟食物。默认 GIF 不自动生成角色肢体动画；目前的状态表现是移动、上下弹动和状态文字。

## 可复用算法

[`src/PetBrain.cs`](src/PetBrain.cs) 不依赖 Windows Forms、文件系统、真实时间或网络。传入时间步长、活动边界、食物列表与暂停状态，读取位置、状态以及被吃掉的虚拟食物 ID。

```csharp
var brain = new PetBrain(42,
    new Bounds(0, 0, 640, 400), new Vec(200, 150));
brain.Size = 80;
brain.Speed = 45;
brain.Step(0.05, foods, pointerNearPet, professional: true);
// brain.Position -> your window / sprite position
// brain.State -> Idle / Wander / SeekFood / Eat / Sleep
// brain.ConsumedFoodId -> remove a VIRTUAL food object
```

浮点坐标用于低速移动；位置被限制在完整角色能容纳的范围内；时间步长最多 100 ms，避免电脑休眠后跳过整个屏幕。固定随机种子可重放同一段行为。详细说明见 [ALGORITHM.md](ALGORITHM.md)。

## 构建与测试

Windows 10/11，.NET Framework 4.x。构建使用系统的 `csc.exe`，无需下载 NuGet 包。

```powershell
.\build.ps1 -Test
```

结果位于 `dist/`，包含三个 EXE 和共享的 `assets/`。CI 在 Windows runner 上执行同一构建和核心测试。

本地原生界面集成测试：

```powershell
.\test-app.ps1
```

集成测试在 `dist/` 下使用独立临时配置，测试多个入口、GIF 导入、尺寸保存、安全移除和关闭，并输出本地界面预览图。不会更改真实 app 或文件夹，不自动设置开机启动。

## 资源与边界

- 仍然需要后台进程，不是“零后台动态图标”。原生版省去 Electron，但 .NET、界面和 GIF 解码仍有成本。
- 一次本机测试：低配版单挂件、管理页未打开时约 90 MB 工作集。仅供参考，不是内存上限或跨机器保证；素材、挂件数量、系统和界面操作都会影响占用。
- 当前框选及自动找回以主显示器的工作区为准；跨显示器活动范围尚未实现。
- 使用 Windows Forms 透明色窗口；包含洋红色的素材可能出现透明像素，半透明边缘不等同于逐像素 alpha 图层。
- 同时投喂最多 8 个虚拟食物；草自动生成时最多保留 3 个食物。
- 退出会保存位置；强制结束进程可能丢失最后一次位置变动。
- 发布包未做代码签名。没有自动更新、遥测、网络上传或后台下载。

配置保存在 `%LOCALAPPDATA%\BouncyIcons\<版本>\`。仓库和发布包不包含个人快捷方式、绑定路径、日志或用户 GIF。
